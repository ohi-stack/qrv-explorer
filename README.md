# QR-V™ Registry Explorer — Consolidated Source Archive

The public registry explorer now lives on the main QR-V platform:

```text
https://qrv.network/explorer
https://qrv.network/registry
https://qrv.network/registry/{QRVID}
```

Registry data is retrieved through the canonical API node at `api.qrv.network`.

This repository is retained for explorer UX history and future advanced search features. It is not a required standalone production application after two-node cutover.

If `explorer.qrv.network` remains in DNS, point it to `qrv-node`; the platform redirects it to `qrv.network/explorer`.
